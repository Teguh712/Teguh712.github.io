Instalasi Oracle SQL Developer & Oracle Database XE 21c

Dokumentasi Project by Teguh Ramadhan

1
Download Oracle SQL Developer

Buka Google Chrome, ketik oracle sql developer download lalu pilih menu SQL Developer Download.

2
Pilih Versi Installer

Pilih Windows 64-bit with JDK 17 included lalu download.

3
Extract File

Setelah download selesai, file berbentuk .rar. Extract file tersebut hingga muncul folder SQL Developer.

4
Jalankan SQL Developer

Cari file sqldeveloper.exe, klik kanan lalu pilih Run as Administrator.

Oracle SQL Developer adalah IDE berbasis Java untuk mengelola database Oracle termasuk Oracle XE.

5
Install Oracle Database XE

Download Oracle Database XE 21c dari situs resmi Oracle. Setelah selesai, extract file lalu jalankan setup.exe sebagai Administrator.

6
Setujui License

Pilih I accept the terms in the license agreement lalu klik Next.

7
Setting Password Database

Masukkan password database. Password ini akan digunakan untuk login ke database dan membuat koneksi baru.

8
Selesai Instalasi

Klik Next lalu Finish. Instalasi Oracle Database XE selesai.
