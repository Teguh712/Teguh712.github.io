Panduan Instalasi Oracle SQL Developer & Oracle XE

Langkah 1

Buka Google Chrome, ketik oracle sql developer download lalu klik SQL Developer Download.

Langkah 2

Pilih Windows 64-bit with JDK 17 included lalu download.

Langkah 3

Setelah selesai download, file berbentuk .rar. Lakukan extract.

Langkah 4

Cari file sqldeveloper.exe, klik kanan → Run as Administrator.

Langkah 5

SQL Developer berhasil dibuka. Selanjutnya lakukan instalasi Oracle Database XE.

Langkah 6

Download Oracle Database XE, extract file lalu jalankan Setup → Run as Administrator → Next.

Langkah 7

Pilih I accept the terms in the license agreement lalu klik Next.

Langkah 8

Masukkan Password Database. Password ini akan digunakan saat membuat koneksi di SQL Developer.

Langkah 9

Klik Finish dan tunggu sampai instalasi selesai.

Instalasi selesai. Oracle siap digunakan 🎉
