Instalasi Oracle Database XE 21c & SQL Developer

Dokumentasi Project by Teguh Ramadhan

1. Download Oracle XE

Download Oracle XE 21c dari website resmi Oracle.

2. Install Oracle XE

  1. Jalankan setup.exe
  2. Klik Next → Accept → Install
  3. Tunggu hingga selesai

3. Install SQL Developer

Download SQL Developer 24 dan extract, lalu jalankan sqldeveloper.exe

4. Cek Listener

lsnrctl status

5. Fix Error ORA-12514

ALTER SYSTEM REGISTER;

6. Test Login

password : ********
